# Skill: Solution Folder Structure

## Repository Layout

```text
/
├── src/
│   ├── api/             # .NET REST API
│   ├── charts-api/      # Node charts API
│   ├── app/             # React + Vite app (editor and subscriber designs)
│   │   └── src/
│   │       ├── shared/  # Code used by both designs
│   │       ├── editor/
│   │       └── subscriber/
│   ├── libs/            # Shared .NET libraries and EF migrations
│   ├── services/        # Background and ingest services
│   ├── playwright-automation/ # Browser and API end-to-end tests
│   ├── tests/           # .NET test projects
│   └── tools/           # Utility scripts and helper tools
├── dependencies/
│   ├── elasticsearch/
│   ├── kafka/
│   ├── kafka-ui/
│   ├── keycloak/
│   ├── nginx/
│   ├── oracle/
│   ├── postgres/
│   ├── reverse-proxy/
│   └── tools/           # Database helper images
├── openshift/           # Kubernetes manifests and deployment scripts
├── docs/
└── Makefile
```

## Where To Make Changes

- UI features and forms: `src/app/src/editor/**` or `src/app/src/subscriber/**`
- Shared React components/types/hooks: `src/app/src/shared/**` (imported as `@/shared`)
- API endpoints and auth logic: `src/api/**`
- Background workers and ingestion pipeline: `src/services/**`
- Shared C# domain/data/services: `src/libs/**`
- Database schema and data migration scripts: `dependencies/postgres/**`
- Infra/runtime settings: `docker-compose*.yml`, `openshift/**`, `dependencies/keycloak/**`

## Important Structure Rules

- Do not import between `src/app/src/editor` and `src/app/src/subscriber`, or from either into `src/app/src/shared`; move shared code to `src/app/src/shared`. Oxlint and the build enforce this.
- Add new DB changes as new SQL migrations in `dependencies/postgres/`; do not rewrite historical migrations.
- Keep environment values in `.env` files (generated by `make setup`), not committed secrets.

# Skill: Solution Folder Structure

## Repository Layout

```text
/
|- app/               # React + Vite web app (Node 26, npm); one image, APP_MODE picks the design
|  |- src/shared/      # Code used by both designs
|  |- src/editor/      # Editor design (admin/editor UI)
|  |- src/subscriber/  # Subscriber design
|- api/
|  |- net/             # Main .NET API (REST + SignalR)
|  |- node/            # Node charts API
|- services/
|  |- net/             # .NET background and ingest microservices
|- libs/
|  |- net/             # Shared .NET libraries
|- db/
|  |- postgres/        # SQL migrations and database scripts
|  |- elasticsearch/   # Elastic bootstrap config
|  |- kafka/           # Kafka topic/migration scripts
|- auth/keycloak/      # Keycloak realm and container config
|- network/nginx/      # Reverse-proxy config
|- openshift/          # Kustomize + deployment manifests
|- test/               # Integration/Postman-oriented testing artifacts
|- tools/              # Utility scripts and helper tools
```

## Where To Make Changes

- UI features and forms: `app/src/editor/**` or `app/src/subscriber/**`
- Shared React components/types/hooks: `app/src/shared/**` (imported as `@/shared`)
- API endpoints and auth logic: `api/net/**`
- Background workers and ingestion pipeline: `services/net/**`
- Shared C# domain/data/services: `libs/net/**`
- Database schema and data migration scripts: `db/postgres/**`
- Infra/runtime settings: `docker-compose*.yml`, `openshift/**`, `auth/keycloak/**`

## Important Structure Rules

- Do not import between `app/src/editor` and `app/src/subscriber`, or from either into `app/src/shared`; move shared code to `app/src/shared`. Oxlint and the build enforce this.
- Add new DB changes as new SQL migrations in `db/postgres/`; do not rewrite historical migrations.
- Keep environment values in `.env` files (generated by `make setup`), not committed secrets.
